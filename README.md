# Escape from Kotlin
An android game heavily inspired by Wolfenstein 3D made in Android Studio and Kotlin from scratch.
Uses an unique way of rendering with raycasted walls but sprite based entities.
Most of the functions of Wolfenstein 3D have been recreated some improved heavily.
